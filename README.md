# LLM-projects

Учебный репозиторий с практическими заданиями по большим языковым моделям (LLM).

В репозитории собраны Jupyter Notebook-файлы, отчёты и учебные материалы по основным этапам работы с языковыми моделями:

- запуск и тестирование готовых LLM;
- оценка качества моделей;
- токенизация и сравнение моделей;
- построение RAG-систем;
- prompt engineering;
- instruction tuning;
- fine-tuning с использованием LoRA.

## Структура репозитория

```text
LLM-projects/
└── Tix/
    ├── 1/
    ├── 2/
    ├── 3/
    ├── 4/
    ├── 5/
    └── 6/
```

Папки внутри `Tix` соответствуют отдельным практическим заданиям или темам курса.

## `Tix/1` — базовый запуск и сравнение LLM

В папке находятся примеры простого запуска языковых моделей и материалы по архитектуре Transformer.

Основные файлы:

- `simple_llm_inference exmpl.ipynb` — базовый пример инференса языковой модели;
- `simple_llm_inference_1.ipynb` — эксперименты с моделью;
- `simple_llm_inference_2.ipynb` — дополнительные эксперименты;
- `Основы_LLM_2026_Лекция_2_архитектура_трансформер.pdf` — лекционные материалы об архитектуре Transformer;
- `Отчет.txt` — результаты сравнения моделей.

В работе сравниваются модели:

- `RefalMachine/RuadaptQwen3-4B-Instruct`;
- `LiquidAI/LFM2.5-1.2B-Instruct`.

Эксперименты посвящены проверке качества ответов моделей на общие вопросы, вопросы с подвохом, творческие задания и задачи на рассуждение.

## `Tix/2` — токенизация и оценка моделей

Папка посвящена оценке качества языковых моделей на русскоязычных наборах данных.

Основные файлы:

- `z2_liquid.ipynb` — эксперименты с моделью LiquidAI;
- `z2_qwen.ipynb` — эксперименты с моделью Qwen;
- `Основы_LLM_2026_Лекция_3_evaluation,_токенизация.pdf` — материалы по токенизации и оценке LLM;
- `Отчет.txt` и `Отчет.pdf` — описание экспериментов и результатов.

Используются датасеты:

- `RussianNLP/coat` — классификация текстов;
- `RussianNLP/russian_super_glue` — задачи русского языкового понимания, включая PARus.

Для оценки используются метрики:

- Accuracy;
- Precision;
- Recall;
- F1-score.

## `Tix/3` — эмбеддинги, векторный поиск и RAG

Папка содержит реализацию Retrieval-Augmented Generation (RAG).

Основные файлы:

- `liquid.ipynb` — RAG-система на основе модели LiquidAI;
- `qwen.ipynb` — RAG-система на основе модели Qwen;
- `simple_llm_inference exmpl.ipynb` — пример базового инференса;
- `Основы_LLM_2026_Лекция_4_BERT,_Sentence_BERT,_векторные_БД,_RAG.pdf` — материалы по эмбеддингам, BERT, векторным базам данных и RAG;
- `Отчет.txt` и `Отчет.pdf` — результаты эксперимента.

В рамках задания:

1. загружается датасет `bearberry/rus_xquadqa`;
2. формируется единый корпус документов;
3. удаляются дубликаты;
4. создаются эмбеддинги с помощью модели E5;
5. документы индексируются в Qdrant;
6. реализуется поиск релевантных документов;
7. найденный контекст передаётся языковой модели;
8. ответы сравниваются с эталонными ответами датасета.

Для интеграции компонентов используется LangChain.

## `Tix/5` — prompt engineering и instruction tuning

Папка посвящена созданию промптов и обучению моделей следовать инструкциям.

Основные файлы:

- `Instruction_tuning_example (2).ipynb` — пример instruction tuning;
- `z5_liqiud.ipynb` — эксперименты с моделью LiquidAI;
- `Основы_LLM_2026_Лекция_6_Промптинг,_alignment_.pdf` — материалы по промптингу и alignment;
- `Отчет.txt` и `Отчет.pdf` — результаты экспериментов.

В работе исследуется влияние instruction tuning на качество моделей при решении задач классификации.

Рассматриваются датасеты:

- `RussianNLP/coat`;
- `RussianNLP/russian_super_glue`.

Сравниваются результаты модели:

- до дополнительного обучения;
- после instruction tuning.

Основная цель — проверить, улучшается ли качество ответов модели после обучения на примерах с инструкциями.

## `Tix/6` — fine-tuning и LoRA

Папка посвящена дообучению языковых моделей с помощью методов fine-tuning и LoRA.

Основные файлы:

- `Instruction_tuning_example_lora.ipynb` — пример instruction tuning с использованием LoRA;
- `Instruction_tuning_example_lora_4bit (1).ipynb` — вариант обучения с 4-битной квантизацией;
- `Основы LLM 2026. Лекция 7_ finetuning, LoRa.pdf` — теоретические материалы по fine-tuning и LoRA.

LoRA позволяет обучать небольшое количество дополнительных параметров вместо полного изменения всех параметров большой языковой модели. Это снижает требования к видеопамяти и вычислительным ресурсам.

Вариант с 4-битной квантизацией предназначен для более экономичного запуска обучения на ограниченном оборудовании.
